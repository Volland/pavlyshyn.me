# Exactly one graph device on the site

`/books` gets the Concept Graph — books as nodes, Themes as hubs, drawn in the Llull-wheel idiom. `/cv`
gets a Timeline instead, despite a career graph being the thematically obvious choice for an author who
writes about knowledge graphs.

The reasoning is that a device used once is an argument and a device used everywhere is a tic. A graph
also happens to be a worse way to read employment history than a time axis.

Recorded because the temptation to add a third graph will recur on every new page, and because the
absence of one on `/cv` looks like an omission rather than a decision.
