# About

**Sovereign Agentic AI** is a newsletter about how an AI agent remembers — and what it remembers on.

The industry has largely settled on an answer: put everything in a vector store, retrieve the nearest chunks, hand them to a model. That is retrieval. It is not memory. Memory has structure, it has time, it consolidates and it forgets, and it lets you ask *why* something is true rather than only *what* resembles it. This newsletter is about building the second thing.

## What I write about

- **Agentic memory** — episodic, semantic and procedural layers; the extraction-and-consolidation pipeline that keeps a memory from rotting; causal reasoning over recall.
- **Graph substrates** — embedded and columnar graph databases, Semantic Spacetime ontologies, metagraphs and higher-order structure, promise graphs.
- **Hybrid Graph RAG** — what happens when vector search, graph traversal, PageRank and community detection are fused into one query instead of picked between. On multi-hop questions, +109% against vector-only retrieval.
- **Edge and local-first AI** — knowledge graphs that ship as a single file and run in-process. No server, no network hop, nothing leaving the device.
- **Sovereign agents** — DIDs, KERI, verifiable credentials, agent reputation and trust registries. Identity for agents, and trust between them without a central authority.

Posts tend to be long, specific, and full of things that did not work. If you want takes on the model release of the week, this is the wrong newsletter.

## The tools

Three VS Code extensions, one conviction: draw the model, ship the text. You model visually because a diagram is how a person understands structure, then you commit plain, schema-validated JSON, because text is what diffs, merges and reviews. The picture is disposable. The model is the asset.

- **Factum ORM** — conceptual schemas in ORM 2, verbalized back as English sentences a domain expert can confirm or reject.
- **LPG Modeler** — design a property graph once, generate LadybugDB DDL, Neo4j constraints, SHACL shapes and an OWL ontology from it.
- **Causal Canvas** — causal models that tell you when you are adjusting for a collider.
